How it works

📤

1. Issue

Registrar uploads PDF. Gemini 2.0 Flash OCR auto-fills all fields.

⛓️

2. Mine

SHA-256 PoW consensus anchors the credential hash to the ledger.

🎓

3. Wallet

Student gets an email, views their 3D document inspector, shares QR.

✅

4. Verify

Employer scans QR → cryptographic check in < 5 seconds. Done.

🤖

Gemini 2.0 Flash OCR

Multimodal AI extracts student name, roll number, DOB and credential type from any PDF or image — zero manual entry.

⛓️

PoW Blockchain Ledger

Every credential is anchored with SHA-256 proof-of-work. Tampering a single byte breaks the entire chain instantly.

📱

60-Second Dynamic QR

Time-boxed, single-use QR codes prevent screenshot fraud. The QR expires — the blockchain record never does.

🔬

3D Holographic Inspector

WebGL Three.js document viewer with block explorer, visual hash swatches and live chain validation status.

🏛

3 Campuses, 1 Platform

JIIT Noida · JUIT Waknaghat · JUET Guna — each with their own branded portal, logo and registrar gateway.

🔒

AES-256 PDF Encryption

Downloaded stamped PDFs are password-locked with the student's DOB. Only the genuine holder can open it.

📡

MCP Agent API

Full Model Context Protocol server — any AI agent (Claude, Antigravity, custom BGV bots) can audit credentials over JSON-RPC.

✉️

Email Notifications

Transactional Gmail SMTP for every issuance, correction request and verification event — with branded templates.
